大狗AI画布使用与 Agent

大狗AI画布提供 Codex App 插件，把 Codex 和本地 Canvas Agent 连接起来。安装后，可以让 Codex 打开画布、读取节点、创建节点、连接流程并触发生成。

安装 Codex App 插件

把下面的请求发给 Codex：

请从 https://github.com/esncy/infinite-canvas.git 安装大狗AI画布 Codex 插件。
请 clone 仓库到 ~/plugins/infinite-canvas，确认 plugins/infinite-canvas/.codex-plugin/plugin.json 存在，
把仓库加入 personal marketplace，再安装 infinite-canvas 插件。

也可以手动安装：

mkdir -p ~/plugins
git clone https://github.com/esncy/infinite-canvas.git ~/plugins/infinite-canvas
cd ~/plugins/infinite-canvas
codex plugin marketplace add "$(pwd)"
codex plugin add infinite-canvas@infinite-canvas-local

使用插件

打开大狗AI画布新建画布并连接好 Codex
读取当前画布并总结节点结构
根据选中节点创建一组生图提示词

插件会启动本地 Canvas Agent，然后打开本地测试站：

http://localhost:4000/canvas?mode=new&agentUrl=<Local URL>&agentToken=<Connect token>

手动启动 Agent：

npx -y @esncy/canvas-agent
npx -y @esncy/canvas-agent mcp

MCP 服务名继续使用 infinite-canvas，内部 Agent 服务名继续使用 canvas-agent。包名是 @esncy/canvas-agent。

本地连接原理

        |
        v

        |
        v
浏览器画布 React 状态

Canvas Agent 默认监听 http://127.0.0.1:17371，启动后生成 Connect token。网页通过 SSE 接收工具调用，画布状态通过 Agent 同步，Codex 调用工具时由 Agent 转发到浏览器。

安全与配置

  • Canvas Agent 默认只监听 127.0.0.1，网页连接必须携带 Connect token。
  • AI API Key、画布、素材和生成记录默认保存在浏览器本地。
  • NEW API 只作为用户填写的 OpenAI 兼容 Base URL；用户在自己的 /token 页面创建 API Key。
  • 内置提示词按公开来源运行时读取，提示词图片和 JSON 不在本 Fork 内复制。
文档入口 · 节点操作

节点与快捷键

文本节点保存提示词和说明，图片节点用于生成与参考，视频节点用于视频输入或生成。节点可以通过连线组成可重复的创作流程。

文本节点

  • 双击文本节点内容区域直接编辑。
  • 选中文本节点后，使用顶部工具栏的“编辑文字”进入编辑状态。
  • 输入框支持 @ 引用已连接的图片、文本、视频和音频资源。
  • 输入框里的模型来自全局配置；没有模型时，先在配置中拉取或手动填写模型名。

图片节点

  • 文本节点点击“生图”会在右侧创建生成配置节点并开始生成。
  • 选中空图片节点点击“生成”会直接回填当前节点；数量大于 1 时继续创建子图节点。
  • 已有内容的图片节点会沿用图片作为参考图。
  • 生成节点会记录提示词、生成类型、模型、尺寸、数量和参考图引用，便于重试。

视频节点

  • 可以通过工具栏新建视频节点，也可以拖入或上传本地视频。
  • 空视频节点可以输入提示词生成视频，结果会回填当前节点。
  • 视频模式会读取上游文本作为 prompt，读取图片和视频作为参考输入。

推荐流程

  1. 新建文本节点，写入图片创作想法。
  2. 用节点下方对话框优化或扩写提示词。
  3. 确认文本后点击“生图”。
  4. 在生成配置节点调整模型、比例和数量，再次生成。

视图与编辑快捷键

  • 拖动画布空白处：平移视图；鼠标滚轮：缩放画布。
  • Ctrl / Cmd + A：全选节点。
  • Ctrl / Cmd + C / Ctrl / Cmd + V：复制和粘贴节点。
  • Delete / Backspace：删除节点或连线。
  • Esc：取消选择并关闭当前浮层。
  • Ctrl / Cmd + Z：撤销。
  • Ctrl / Cmd + Shift + Z 或 Ctrl / Cmd + Y：重做。
撤销和重做记录节点、连线、视口、背景模式和助手会话变化；项目名称、账号状态、全局 AI 配置和“我的素材”保存操作不属于当前画布历史。
